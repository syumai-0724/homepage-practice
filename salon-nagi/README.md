# hair salon Nagi — 美容院ホームページの練習

10代・20代を想定した、架空の美容院の学習用サイトです。人物・紹介・イラスト・料金はサンプルです。

## ファイルの役割

- index.html：店の紹介、21種類のメニュー、7人のスタッフ、店舗情報を管理します。イラストもHTML内のSVGで描いています。
- style.css：色、文字、配置、スマホ対応を管理します。先頭の変数で配色を変更できます。
- README.md：この説明書です。

## 店舗設定

- 営業：9:00〜18:00。毎週火曜日休み。
- アクセス：長野駅から約5分。移動手段と店舗住所は未指定です。地図リンクは長野駅を表示します。
- 全メニュー：各500円（税込・仮料金）。組み合わせのセット価格ではありません。
- スタッフ：7人。韓国風レイヤー、メンズマッシュ、透明感カラー、ショートボブ、デザインカラー、パーマ、ヘアアレンジをそれぞれ担当します。
- 実際の予約受付・連絡先は未指定です。予約ページはブラウザー内に保存する練習用デモです。

## 編集方法

文章・価格・スタッフ紹介はindex.html、色・余白・並び方はstyle.cssを編集してください。HTMLとCSSを同じフォルダーに置くと、index.htmlをブラウザーで開けます。メニューの見出しを押すと開閉できます。

カフェとは別のsalon-nagiフォルダーに保存します。GitHubのmainへの反映後、GitHub Pagesが自動更新します。

## 予約デモのファイルと使い方

- booking.html：担当者・複数メニュー・日付・時間・ニックネームと、担当者の休み設定の入力画面。
- booking.css：予約ページの配置、空き時間・選択中・予約不可の見た目。
- booking-model.js：担当者、メニュー、日付、30分枠、重複予約などのルール。
- booking.js：画面の更新、予約の保存、キャンセル。JavaScriptは操作と保存を担当します。

ホームまたは各スタッフのリンクから予約ページに移動できます。担当者7人は全員指名料100円。メニューは1つ500円、指名料は1予約につき100円。合計は500円×選択メニュー数＋100円（税込・仮料金）です。

9:00〜17:30開始の18枠を用意し、メニューごとの仮の所要時間を合計します。必要な時間すべてが連続して空いている開始時刻だけを選択できます。18:00は閉店時刻のため開始枠には含みません。火曜定休、過去の時間、同じ担当者の予約済み枠は選択できません。別の担当者なら同時刻を予約できます。

予約データはlocalStorageのnagi-booking-demo-v1に保存します。同じブラウザー・同じ公開先で再読み込みしても残り、キャンセルすると空き枠に戻ります。別の端末やブラウザーとは共有されず、実際の予約受付やメール送信は行いません。ブラウザーのデータ消去で予約は消えます。保存が使えない場合はエラーを表示します。

本番の多人数での予約受付にはサーバー側での共有・重複制御が必要です。価格や所要時間も本番用に見直してください。

確認済み：担当者ごとの重複判定、キャンセル後の空き時間、火曜日、過去時間、閉店時刻、日本時間の日付、保存データの検証、JavaScript構文。実ブラウザーでの操作確認は未実施です。

## 複数メニュー・画像・休み設定

メニューはチェックボックスで複数選択できます。カットとワンカラーなら150分・1,100円です。指名料は1予約につき100円だけ加算します。所要時間はデモ用の仮設定です。

予約済み時間と少しでも重なる予約、閉店18:00を超える予約は保存できません。同じ日・時刻でも別の担当者は予約できます。旧デモの1メニュー予約も引き継ぎます。

担当者の画像はstaff-yui.svgなど7枚のイメージイラストです。実際の写真にする場合は写真を同じフォルダーに置き、booking-model.jsの各スタッフのimageをそのファイル名に変更してください。

休み設定の編集はスタッフ限定の管理画面へ移す予定です。現在、お客様の予約ページに休み設定の操作欄はありません。休みの日は予約不可で、解除すれば空き時間に戻ります。予約がある日は先に該当のデモ予約をキャンセルしてください。火曜日の定休日は解除できません。休み設定はこのブラウザーのlocalStorage（nagi-booking-holidays-v1）に保存され、別端末とは共有しません。

確認済み：複数選択の料金と時間、途中の予約との重複、隣接枠、閉店時刻、担当者ごとの休み、旧予約データの引き継ぎ、画像参照、JS構文。実ブラウザーでの操作確認は未実施です。

## ヘアスタイル集

styles.htmlを追加しました。韓国風レイヤー、切りっぱなしボブ、丸みショート、メンズマッシュ、ニュアンスパーマ、ミルクティーベージュ、ピンクのインナーカラー、リボンハーフアップ、ゆる編みおろしの9種類です。

- styles.html：9スタイルの紹介、ポイント、担当者の予約リンク。
- styles.css：カード、絞り込みボタン、スマホ用レイアウト。
- styles.js：長さ・カラー・アレンジなどによるカテゴリー絞り込み。
- styles/*.svg：9枚の学習用イラスト。実際の施術例ではありません。

ホームページにも3スタイルの紹介を追加しました。各スタイルの「担当者で予約する」から、該当スタッフが選択された予約デモへ進めます。実際の写真が用意できたらstyles.htmlとホームの画像ファイル名を差し替えられます。

## FAQ（よくある質問）

ホームのFAQセクションとfaq.htmlの専用ページに、同じ30問を表示します。カテゴリーは予約6問・料金5問・カットとカラー6問・パーマ4問・来店と設備5問・その他4問です。

- faq-data.js：カテゴリー名・質問・回答のデータ。質問と回答の文面はこの1ファイルで編集できます。
- faq.js：質問の開閉、カテゴリー表示、質問と回答のキーワード検索、検索件数、リセット。
- faq.css：FAQの余白・配色・開閉アニメーション・スマホ表示。
- faq.html：FAQ専用ページ。ホームにも同じFAQを掲載しています。

質問を追加するときはfaq-data.jsの該当カテゴリーのitemsに、id（重複しない名前）、question、answer、needsConfirmationを持つデータを追加してください。件数とカテゴリー表示は自動で更新します。未確定の店舗情報はneedsConfirmation:trueで「要確認」を表示し、正式情報を確認してから文面とフラグを変更してください。

検索は質問と回答の両方を対象にし、カテゴリー条件と組み合わせます。空白で区切った複数のキーワードはすべてを含むFAQを表示します。全角英数字の表記差を正規化します。質問の内容はtextContentで表示し、HTMLとして実行しません。

すべて閉じた状態で始まり、複数の質問を同時に開けます。質問はbutton要素なので、Tabで移動しEnterまたはSpaceで操作できます。aria-expandedとaria-controlsで開閉状態・回答との対応を示し、閉じている回答はhiddenとinertで操作対象から外します。動きを減らす設定ではアニメーションを無効にします。

問い合わせ先は未設定のため、仮リンクを設けず「準備中・設定が必要」と表示しています。既存の予約デモへ進むボタンはありますが、実際の問い合わせや来店予約を送信するものではありません。

確認済み：30問とカテゴリーごとの件数、回答の2〜4文、初期閉じ状態、複数展開、＋/−、ARIA対応、連続開閉、カテゴリー切り替え、質問/回答検索、検索とカテゴリーの併用、0件表示、リセット、ページリンク。既存の予約ルールとスタイル絞り込みも再確認しました。外部ライブラリは追加していません。

実ブラウザーの起動がこの環境では失敗したため、スマホ・タブレット・PCでの実描画、実キー操作、アニメーションの見た目は未確認です。レスポンシブCSSとDOM操作の確認は実施しています。

## 施術時間とスタッフ用管理画面の分離

予約開始は30分単位ですが、施術時間はカット60分・ワンカラー90分・縮毛矯正180分など、booking-model.jsのserviceMinutesでメニューごとに設定します。複数選択すると時間を合計し、閉店や既存予約と重なる開始枠を選べなくします。金額は引き続き各500円＋1予約につき指名料100円です。

新規予約にはdurationMinutesを保存し、後でメニュー時間が変わっても予約の終了時刻を維持します。旧デモの予約は当時の1メニュー30分として引き継ぎます。

お客様向け予約ページから休み設定の操作欄を取り除きました。既存の休みデータは引き続き空き時間の判定に使います。管理用カレンダーは、認証と予約データ共有を用意するまでGitHub Pagesに公開しません。URLやJavaScriptのパスワードだけを隠す方法はアクセス制限として扱いません。

現在の予約はブラウザー内のデモであり、スタッフ用サーバーへは送信されません。全端末で共有する管理カレンダーには認証付きサーバーと共有データベースへの接続が必要です。
