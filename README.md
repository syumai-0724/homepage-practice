# こもれび珈琲 — ホームページの作成練習

## ファイルの役割

- `index.html`：ホームページ本体。HTMLとCSSを1ファイルにまとめています。指定住所のGoogleマップ、写真用の枠、XとInstagramの準備中の欄を含みます。
- `cafe.jpg`：トップに表示する店内写真。現時点ではGitHubへの追加待ちです。index.htmlと同じ場所にアップロードしてください。
- `README.md`：この説明書。ホームページには表示されません。

## 更新の流れ

1. CodexでHTMLを編集します。
2. 変更した内容をGitHubのmainブランチに反映します。
3. GitHubと連携した公開サービスが、最新のmainを使ってホームページを更新します。

公開サービスへの接続が完了するまでは、GitHubへの反映だけではWeb公開されません。

## GitHub Pagesを使う場合

GitHubのSettings → Pagesで、SourceをDeploy from a branch、Branchをmain、フォルダーを/(root)に設定してSaveします。その後、mainが更新されると公開ページも自動更新されます。すでに別の公開サービスを使っている場合は、そのサービスの設定を確認してください。
