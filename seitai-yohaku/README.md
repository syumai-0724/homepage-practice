# 整体室 余白 — デザイン確認版

架空の整体院のトップページです。既存のカフェ・美容室・ネイルサロンのファイルは変更しません。**本番公開、外部サービス契約、実際の予約受付は行っていません。**

## 確認方法

同梱の `preview.html` をダブルクリックしてブラウザーで開けます。インターネット接続やNode.jsは不要です。これはNext.jsと同じReactコンポーネントから生成した、画像・CSS・スクリプト入りのデザイン確認用HTMLです。

開発環境ではNode.js 22以上（制作時24）を用意し、以下を実行します。

```sh
npm ci
npm run dev
```

PCで実行した場合は `http://localhost:3000` を開きます。クラウドで起動したlocalhostは、お手元のPCからそのまま開くURLではありません。クラウドのポート転送機能が必要です。この確認版には、ポート転送に依存しない `preview.html` を用意しています。

```sh
npm run typecheck
npm run build
npm run preview:html
```

`npm run build` はNext.jsの静的出力 `out/` を作成します。公開するコマンドではありません。現段階の `npm run start` は使わず、静的出力の確認には `python -m http.server 8000 --directory out` を使えます。

- トップページ：ヘッダー、キャッチコピー、通いやすさ、3コースの料金・時間、初回の流れ、スタッフ、FAQ、アクセス・営業時間、予約案内、フッター。
- モバイルメニュー（Escapeで閉じる）、下部固定の予約案内ボタン。
- メニュー詳細ダイアログ、予約準備中ダイアログ、プライバシー案内。
- 複数開けるFAQ、キーボード操作、ダイアログのフォーカス制御。
- スクロール時の控えめな表示、アニメーション軽減設定、読み上げラベル。
- 未設定の住所・電話番号・地図、仮データであることの表示。
- 医療効果を保証しない表現、実績・資格・口コミの捏造をしない構成。
- プレビューの検索エンジンへの登録を抑える `noindex`。

## ファイルの役割

- `app/page.tsx`：トップページの入口。
- `app/layout.tsx`：日本語・タイトル・説明文・検索除外設定。
- `app/globals.css`：配色、余白、各セクション、モバイル・動きの軽減対応。Tailwind CSS v4を読み込み、見た目の細部は共通CSSで管理。
- `components/home.tsx`：トップページと、ナビ・FAQ・詳細ダイアログなどの操作。
- `lib/site-data.ts`：店舗名・営業時間・料金・メニュー・スタッフ・FAQを一か所で編集。
- `public/images/studio.webp`：この制作のためにAI生成した施術室のイメージ。実在の店舗写真ではありません。
- `public/favicon.svg`：余白をイメージしたオリジナルアイコン。
- `scripts/make-preview.cjs`、`scripts/preview-entry.tsx`：同じReactコードから、持ち運べる `preview.html` を生成。別の予約実装を持つものではありません。
- `DESIGN.md`：全体設計と、デザイン確認後の開発方針。
- `package.json`、`package-lock.json`：使用ツールとバージョン固定。
- `next.config.ts`、`tsconfig.json`、`postcss.config.mjs`：開発・ビルド設定。

## 仮データの編集

`lib/site-data.ts` を変更します。料金・時間・メニュー一覧・詳細画面は同じデータを使います。

現段階では10:00–20:00・水曜休み、30分3,800円／60分6,600円／90分9,000円を**仮設定**にしています。スタッフ2名も架空です。所在地・電話・資格・経歴は未登録で、未確認の実績は表示しません。スタッフ画像は登録前のプレースホルダーです。

## デザイン確認後の開発

現段階では下層ページ・予約カレンダー・個人情報フォーム・予約データベース・メール・管理者ログイン・管理画面は実装していません。ナビはトップページ内の該当セクションへ移動します。予約ボタンを押すと準備中の案内を開き、予約は成立しません。個人情報、Cookie、localStorageへの保存、アクセス解析、広告の読み込みもありません。

次段階は `DESIGN.md` に従って進めます。Supabaseやメール配信サービスの契約、Vercelへの本番公開は承認後に実施します。バックアップ・認証・競合制御・権限・通知は、実装と検証が済むまで本番対応済みとは扱いません。

## 素材

画像はAI生成素材のため、実在の院内や実績と誤認されない表記をしています。フォントは端末の日本語フォントを使い、外部のフォントやCDNに接続しません。配布用プレビューには画像とReactランタイムを同梱します。生成時のライセンス告知は `preview.LICENSE.txt` に保持します。

## 今回の確認結果

- Next.jsの本番ビルド、TypeScriptの型チェックに成功。
- Chromiumで幅320・390・768・1280・1440pxの横はみ出し、画像表示を確認。
